A [[state diagram]] models the behavior of a system by showing its possible states and valid state transitions
A transition is initiated by an event (guard condition)

A [[state table]] is model equivalent to a [[state diagram]]. Its rows represent states, and its columns represent events. Table entries (cells) represent transitions, and contain the target state, al well as the resulting actions.
A [[state table]] explicitly shows invalid transitions, which are represented by empty cells
One test case may, and usually will, cover several transition between states

[[all states coverage]] - coverage items are the states. To achieve 100% coverage, test cases must ensure that all the states are exercised

[[valid transitions coverage]] (0-switch coverage) - coverage items are single valid transitions. To achieve 100% coverage, test cases must exercise all the valid transitions

[[all transitions coverage]] - coverage items are all te transition shown in a state table. To achieve 100% coverage, test cases must exercise all the valid transitions and attempt to execute invalid transitions

[[all states coverage]] is weaker than [[valid transitions coverage]], because it can be achieved without exercising all the transitions
[[valid transitions coverage]] is the most common
