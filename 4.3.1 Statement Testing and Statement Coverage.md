In [[statement testing]] the coverage items are executable statements
The aim is to design test cases that exercise statements in the code
Coverage is measured as the number of statements exercised by the test cases divided by the total number of executable statements in the code

Exercising a statement with a test case will not detect defects in all cases (it may not detect defects that are data dependent) (it may not exercise all the branches in the code)
