[[Checklist testing]] is built on experience
[[Checklist testing]] should not contain items that can be checked automatically, items better suited as [[entry criteria]], [[exit criteria]], or items that are too general

[[Checklist testing]] - Check list items are often phrased in the form of a question. 
[[Checklist testing]] - Check list - It should be possible to check each item separately and directly
[[Checklist testing]] - Check list - Items may refer to [[requirements]], graphical interface properties, quality characteristics or other forms of test conditions.
[[Checklist testing]] - Check list - can be created to support various test types, including functional and non-functional testing
[[Checklist testing]] - Check list - some list may become less effective because devs will learn to avoid making the same errors 
[[Checklist testing]] - Check list - New entries should be regularly updated
