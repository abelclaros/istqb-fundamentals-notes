In [[Exploratory testing]], tests are designed, executed, and evaluated while the tester learns about the test object

[[Exploratory testing]] is session-based, defined timebox. 
[[Exploratory testing]] can use test charters containing test objectives to guide the testing
An [[Exploratory testing]] session is followed by a debriefing/discussion with stakeholders
[[Exploratory testing]] [[test objectives]] may be treated as high-level test conditions
[[Exploratory testing]] Test session sheets used to document the steps followed and discoveries made

[[Exploratory testing]] is useful when there are inadequate specification or there is time pressure
[[Exploratory testing]] is also useful to complement other more formal test techniques
