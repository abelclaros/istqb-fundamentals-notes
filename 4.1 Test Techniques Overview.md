# Introduction
[[Test techniques]] support the tester in [[Test analysis]] (what to test) and in [[Test design]] (how to test). 
[[Test techniques]] help develop a relatively small, but sufficient, set of test cases in a systematic way.
[[Test techniques]] help define test conditions, identify coverage items, and identify test data during the [[Test analysis]] and [[design]]
