# Introduction 
[[Configuration Management]] identifies [[work products]] as [[configuration items]]
[[Configuration Management]] controls [[work products]] as [[configuration items]]
[[Configuration Management]] tracks [[work products]] as [[configuration items]]

([[test plan]], [[test strategies]], [[Test conditions]], [[Test cases]], [[test scripts]], [[Test results]], [[test logs]], and [[test reports]])

[[Configuration Management]] records the items that consist it (relationships, and versions)
When a [[Configuration Management]] item is approved, it becomes a baseline, and it can be changed with a formal change control process

[[Configuration Management]] keeps a record of changed [[configuration items]]

[[Configuration Management]] supports testing by identifying, version control, track changes of [[configuration items]] ([[Traceability]] maintained in the process)
[[Configuration Management]] supports testing by referencing all documentation in [[testware]]

Automated [[Configuration Management]] is included in CI/CD
