# Introduction 
[[Configuration Management]] identifies, controls, and tracks [[work products]] ([[test plan]], [[test strategies]], [[Test conditions]], [[Test cases]], [[test scripts]], [[Test results]], [[test logs]], and [[test reports]]) as [[configuration items]]
```dataview
TABLE  WITHOUT ID
Title,
file.frontmatter.Objective AS Objective,
file.frontmatter.KnowledgeLevel AS KnowledgeLevel

WHERE contains(file.folder, this.file.folder)
WHERE contains(file.frontmatter.Subtitle, "5.4")
FLATTEN "[[" + file.path + "|" + truncate(file.name, 100) + "]]" as Title 
LIMIT 30
SORT Title ASC
```
