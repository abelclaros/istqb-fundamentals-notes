[[Testing Quadrants]] are groups of [[Test levels]] with appropriate test types, activities, [[Test techniques]], and work products

[[Quadrant Q1]] - tech facing, support the team - Component tests and component integration tests - Automated
[[Quadrant Q2]] - business facing, support the team - Functional tests, examples, user story tests, API Testing, simulations. Check [[Acceptance Criteria]] - Manual or Automated 
[[Quadrant Q3]] - business facing, critique the product - exploratory testing, usability testing, user acceptance testing (user oriented) - Manual 
[[Quadrant Q4]] - tech facing, critique the product - smoke tests, non-functional tests (except usability tests) - Automated
