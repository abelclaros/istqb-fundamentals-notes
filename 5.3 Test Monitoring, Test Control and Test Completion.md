# Introduction
[[Test Monitoring]] is concerned with gathering information about testing, so we can assess test progress and see if the [[exit criteria]] is satisfied
[[Test control]] uses the information from [[Test Monitoring]] to provide guidance and corrective actions to achieve most effective and efficient testing (Reprioritizing tests, Re-evaluating entry and exit criteria, adjusting test schedule, adding new resources)

[[test completion]] collects data from completed [[Test activities]] 
[[test completion]] activities occur at project milestones: test level complete, agile iteration finished, test project is completed, release, maintenance release is completed



```dataview
TABLE  WITHOUT ID
Title,
file.frontmatter.Objective AS Objective,
file.frontmatter.KnowledgeLevel AS KnowledgeLevel

WHERE contains(file.folder, this.file.folder)
WHERE contains(file.frontmatter.Subtitle, "5.3")
FLATTEN "[[" + file.path + "|" + truncate(file.name, 100) + "]]" as Title 
LIMIT 30
SORT Title ASC
```
