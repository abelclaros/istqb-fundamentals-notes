In branch testing, coverage items are branches.
The idea is to design test cases to exercise branches
Branch testing will not detect defects in all cases (it may not detect defects requiring the execution of a specific path in code)

Branch coverage sub sumes statement coverage (any set of test cases achieving 100% branch coverage also achieves 100% statement coverage - not viceversa)
