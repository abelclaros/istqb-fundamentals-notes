[[Static testing]] can detect defects in the earliest phases of the [[SDLC]]. Early testing principle [[1.3 Testing Principles]]
[[Static testing]] can also identify defects which cannot be detecte by [[Dynamic testing]]. (e.g., unreachable code, design patterns not implemented as desired, defects in non-executable work products)
[[Static testing]] evaluates the quality, and builds confidence in work products
Since [[Static testing]] is performed early in the [[SDLC]] a shared understanding can be created among the involved stakeholders
Some code defects can be detected using [[Static analysis]] more efficiently than dynamic testing
