[[Static testing]] and [[Dynamic testing]] are complementary

Difference: [[Static testing]] and [[Dynamic testing]] both detect defects, but some defects types can be only detected either by [[Static testing]] or [[Dynamic testing]]
Difference: [[Static testing]] finds defects directly, while [[Dynamic testing]] causes failures from which the associated defects are determined through subsequent analysis
Difference: [[Static testing]] may more easily detect defects that lay on paths through the code that are rarely executed or hard to reach using [[Dynamic testing]]
Difference: [[Static testing]] can be applied to non-executable work products, while [[dynamic testing]] can only be applied to executable work products
Difference: [[Static testing]] can be used to measure quality characteristics that are not dependent on executing code (e.g., maintainability), while [[Dynamic testing]] can be used to measure quality characteristics that are dependent on executing code (e.g., performance efficiency)

Easier to find for [[Static testing]]: Defects in [[requirements]], Design Defects, certain types of coding defects, deviations from standards, incorrect interface specifications, specific types of security vulnerabilities, gaps or inaccuracies in test basis coverage
